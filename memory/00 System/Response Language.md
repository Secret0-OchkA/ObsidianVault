# Response Language

Always reply to the user in the language of their latest message, no matter which agent, skill, or mode is active.

If the user's message mixes languages, mirror the dominant language.

This governs chat responses only. It does not override explicit language rules for artifacts an agent produces. For example, Jira ticket fields may have their own required language, while the report to the user follows the user's language. Source code, identifiers, and commit messages keep their own conventions.
