# Hubs

Хаб — это индексная заметка, которая автоматически показывает заметки с определённым тегом.

## Как это работает

1. Создай хаб по шаблону [[_Templates/Hub]].
2. Выбери тег хаба, например `topic/programming`.
3. Добавляй этот тег в frontmatter или через интерфейс тегов обычных заметок.
4. Хаб автоматически покажет все совпадения в блоке поиска.
5. Для иерархии указывай родительский хаб в `parent_hub` и добавляй ссылку на дочерний хаб в раздел `Дочерние хабы`.

## Соглашение о тегах

- `#hub` — технический тег самой хаб-заметки;
- `#topic/...` — тематические теги, по которым строятся списки;
- один материал может входить в несколько хабов;
- для включения заметок дочерних тем в родительский хаб добавляй заметке также тег родительской темы.

Хабы организуют навигацию, но не заменяют содержательные заметки в `03 Knowledge`.

### Цвета в графе

Цвета в Graph View назначаются группам поиска. Создай в настройках графа следующие группы:

| Группа | Запрос | Рекомендуемый цвет |
| --- | --- | --- |
| Hubs | `tag:#hub` | оранжевый |
| Knowledge | `tag:#knowledge` | синий |
| Projects | `tag:#project` | зелёный |
| Sources | `tag:#source` | жёлтый |
| Meetings | `tag:#meeting` | красный |
| Daily notes | `tag:#daily` | серый |

Шаблоны уже добавляют эти теги автоматически. Поэтому после создания групп цвет будет применяться ко всем новым заметкам соответствующего типа.

### Автоматическое включение заметок

Ссылки внутри хаба прописывать не нужно. Достаточно добавить заметке нужный тег: поисковый блок хаба сам найдёт её.

Важно различать два результата:

- список внутри хаба обновляется автоматически по тегу;
- отдельное ребро в Graph View появляется только из настоящей `[[ссылки]]` в Markdown.

Поэтому автоматический список не обязан создавать обратную ссылку в каждой заметке. Это сохраняет заметки компактными и позволяет одной заметке входить в несколько хабов.

### Плагины

Для текущей схемы плагин не нужен: встроенный блок `query` уже выполняет динамическую группировку.

Если нужны именно автоматические ссылки в Graph View, можно установить `Templater` и настроить шаблон создания заметки: он будет добавлять ссылку на хаб по выбранному тегу. Это отдельная автоматизация, потому что изменение тега после создания заметки не должно незаметно переписывать её содержимое.

`Dataview` полезен для более сложных динамических списков и таблиц, но сам по себе не создаёт постоянные рёбра графа.
