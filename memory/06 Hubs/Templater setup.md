# Автоматические рёбра хабов

Эта система добавляет настоящие `[[ссылки]]` из заметок на подходящие хабы. После этого связи видны в Graph View.

## Текущий вариант: Templater

1. Открой `Settings -> Community plugins -> Templater`.
2. В `Template folder location` укажи `_Templates`.
3. В `Script files folder` укажи `_Scripts`.
4. Для существующих заметок запусти `Templater: Create new note from template` и выбери `_Templates/Sync Hub Links`.

Шаблон найдёт хабы по `hub_tag` и добавит настоящие ссылки в заметки с соответствующими тегами. Повторный запуск не создаёт дубликаты.

## Новые заметки

Включи `Trigger Templater on new file creation`, если эта опция есть в твоей версии Templater. Для рабочих папок назначь `_Templates/Auto Hub Sync` через Folder Templates.

Этот шаблон ничего не вставляет в заметку: он только запускает синхронизацию и не создаёт `Untitled`.

Изменение тега у уже существующей заметки Templater сам не отслеживает, поэтому для таких изменений нужен повторный запуск `Sync Hub Links`.

## Готовый плагин для постоянных ссылок

Подходящий готовый проект: `Related Notes Plugin`.

Репозиторий: `https://github.com/adriaestevam/obsidian-related-notes-plugin`

Он:

- создаёт реальные `[[ссылки]]` между заметками с общими тегами;
- обновляет связи при создании и изменении файлов;
- умеет исключать папки;
- имеет команду `Update all related notes`.

Ограничение: плагин связывает все заметки с общим тегом друг с другом, а не только с хабом. Для связи заметки с хабом у самого хаба должен быть обычный тег в `tags`, например `topic/planning`; свойства `hub_tag` недостаточно.

Плагин пока не опубликован в каталоге Community Plugins и не имеет готового GitHub-релиза. Установка требует Node.js и сборки проекта:

```text
npm install
npm run build
```

Затем скопируй `main.js`, `manifest.json` и `styles.css` в `.obsidian/plugins/related-notes-plugin/`, перезапусти Obsidian и включи плагин.

Перед установкой сделай резервную копию. В настройках плагина отключи `Auto-convert words to tags`, добавь в `Ignored folders` `_Templates`, `_Scripts` и `05 Archive`, а заголовок секции задай как `Hubs`.

`Local Graph Tag Links` можно поставить через BRAT, но он только показывает связи через общие теги в локальном графе и не записывает настоящие `[[ссылки]]`. Для постоянных рёбер он не подходит.


## Слои контекста и автоархив

Для автоматического перемещения старых заметок установлен локальный плагин `Context Layers` в `.obsidian/plugins/context-layers/`.

Он формирует три слоя:

- активные заметки — обычные рабочие папки;
- архивные заметки — `05 Archive/Auto Archive/`;
- Inbox — временный слой для новых материалов.

По умолчанию заметка архивируется после 180 дней без изменений. Хабы, шаблоны, скрипты, README, главный индекс и заметки с защищёнными тегами или активными статусами не перемещаются.

Архивная заметка восстанавливается автоматически при открытии. Если активная заметка содержит настоящую входящую `[[ссылку]]` на архивную заметку, плагин также возвращает её в исходную папку. Исходный путь хранится во frontmatter и удаляется после восстановления.

Автоматическое архивирование не означает удаление. Перед уменьшением срока проверь кандидатов вручную; для важных заметок добавляй `#keep`.
