# Входящие

Сюда попадают быстрые мысли, черновики и новые материалы.

Правило: заметка не должна надолго оставаться здесь. После обработки её нужно:

- превратить в отдельную заметку в `03 Knowledge`;
- связать с проектом или областью;
- перенести в `04 Sources`, если это только внешний материал;
- удалить, если ценности нет.
