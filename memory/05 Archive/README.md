# Архив

Архивные знания — это холодный слой контекста. Они не участвуют в ежедневной работе, но сохраняют историю, ссылки и возможность быстрого восстановления.

## Context Layers

Локальный плагин `Context Layers` автоматически переносит заметки в `05 Archive/Auto Archive/`, если:

- заметка не изменялась заданное число дней (по умолчанию 180);
- у неё нет защищённого тега `#keep`, `#project`, `#source`, `#hub` или `#daily`;
- её статус не `active`, `in-progress`, `blocked` или `draft`;
- это не хаб, шаблон, скрипт, README или главный индекс.

Перед переносом плагин сохраняет исходный путь в frontmatter. Поэтому заметка возвращается в прежнюю папку, когда:

- её открывают напрямую;
- другая заметка начинает ссылаться на неё через `[[ссылку]]`;
- запускается команда `Context Layers: Restore referenced archived notes`.

Архивирование не удаляет файлы. Для окончательного удаления сначала проверь заметки вручную.

## Три слоя контекста

1. **Inbox** — быстрые мысли и необработанные материалы.
2. **Активные знания** — текущие заметки в `01 Projects`, `02 Areas`, `03 Knowledge`, `04 Sources`.
3. **Архивные знания** — старые, но сохранённые заметки в `05 Archive/Auto Archive`.

## Включение

Плагин установлен локально в `.obsidian/plugins/context-layers/`. В Obsidian открой `Settings -> Community plugins`, отключи Safe mode при необходимости, включи `Context Layers`, затем проверь настройки плагина.

До первого запуска рекомендуется оставить срок `180` дней. Для ручной проверки используй команды:

- `Context Layers: Run context layers maintenance`;
- `Context Layers: Archive eligible inactive notes`;
- `Context Layers: Restore referenced archived notes`.
