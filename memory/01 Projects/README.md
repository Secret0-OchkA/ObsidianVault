# Проекты и граница документации

Техническая документация конкретных проектов больше не хранится в Obsidian. Она живёт в соответствующем репозитории и меняется вместе с кодом.

Для PDFService источником истины является репозиторий PDFService, папка `docs/`, входная точка `docs/README.md`.

В Obsidian остаются только общие знания, переиспользуемые практики, workflows, источники и личные заметки. Проектные детали не дублируются здесь и не поддерживаются в этой папке.
